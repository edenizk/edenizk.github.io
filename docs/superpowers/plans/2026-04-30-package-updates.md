# Package Updates Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update all packages in this Vue 2 personal portfolio site to their latest compatible versions and iterate until `npm run serve` and `npm run build` complete without errors.

**Architecture:** The project is a Vue 2 SPA using `@vue/cli-service ~4.x`. We will stay on Vue 2 (not migrate to Vue 3) to avoid breaking template/component changes. The critical constraint is that `node-sass` (deprecated, requires native compilation) should be replaced with `sass` (the pure-JS Dart Sass implementation), which is the modern drop-in for Vue CLI projects. All other packages will be bumped to their latest semver-compatible versions.

**Tech Stack:** Vue 2.7, @vue/cli-service 5.x, Dart Sass (sass), ESLint 8, Webpack 5 (bundled in vue-cli-service 5)

**⚠️ Constraints:**
- Do NOT commit, push, or publish anything
- Node 20 is installed — `node-sass` v4 is incompatible with Node 20 and must be replaced

### Task 8: Iterative error fixing

If any errors remain after Tasks 1–7, use this systematic process:

- [ ] **Step 1: Categorize each error**

For each error, identify:
- Is it a **peer dependency conflict**? → Use `--legacy-peer-deps` or pin the conflicting package.
- Is it a **Webpack config error**? → Check `vue.config.js` for deprecated options.
- Is it a **Sass syntax error**? → Check for `/deep/` selector (Vue 2 syntax) — replace with `::v-deep`.
- Is it a **ESLint rule error**? → Either fix the source or adjust `.eslintrc.js` rule.

- [ ] **Step 2: Fix Webpack 5 breaking changes if needed**

Webpack 5 removed several Node.js polyfills. If you see errors like `Can't resolve 'path'` or `Buffer is not defined`, add to `vue.config.js`:

```js
const { defineConfig } = require('@vue/cli-service')
module.exports = defineConfig({
  configureWebpack: {
    resolve: {
      fallback: {
        path: false,
        os: false,
        crypto: false,
      }
    }
  },
  css: {
    loaderOptions: {
      sass: {
        // If using sass-loader >=12, use 'additionalData' not 'prependData'
        additionalData: ''
      }
    }
  }
})
```

- [ ] **Step 3: Re-run build after each fix**

```bash
npx vue-cli-service build 2>&1 | tail -20
```

Repeat until `Build complete.` with no errors.
